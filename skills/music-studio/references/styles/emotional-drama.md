# Emotional, drama

Sounds like: Samuel Barber's Adagio, Max Richter, Hans Zimmer's slow themes, Thomas Newman. For loss, memory, a quiet triumph, a documentary's closing scene.

| | |
|---|---|
| Tempo, metre | 4/4 or 3/4 at 56 to 80 |
| Key, mode | minor, or major with emphasis on vi and the minor iv |
| Harmony | `i bVI bIII bVII`, `vi IV I V`, `I iii IV iv`; suspensions everywhere; a pedal bass under changing chords |
| Melody | long notes, stepwise, a few aching leaps (a sixth up), suspensions resolving down; the melody repeats with more voices each time |
| Rhythm | almost none: sustained notes, slow harmonic rhythm, the build comes from adding octaves |
| Orchestra | strings alone or nearly: celli on the melody first, then violins an octave up, then both; basses on a pedal; horns at the peak only; choir "a" softly behind |
| Form | one theme stated three times, each larger (one voice, two octaves, full strings and horns), then a sudden quiet ending |
| Signature devices | the melody moving up an octave for the last statement, a suspended chord that resolves at the very end, silence before the last chord |
| Pitfalls | percussion; too many notes; an even dynamic; a climax that does not get quiet again |
| In this studio | `celli`, `violins`, `violas`, `basses` long with careful `expr` curves; `horns` long at the peak; `choir` altos and tenors on "a"; `harp` for single notes |
